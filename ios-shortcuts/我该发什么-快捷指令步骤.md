# 我该发什么（iPhone 快捷指令）

## 目标

用文字或语音描述最近想分享的事情，生成 3 个适合 X 的选题、切入角度、开头和内容结构。

## 快捷指令信息

- 名称：`我该发什么`
- 输入：文字或听写内容
- 模型接口：`POST https://api.deepseek.com/chat/completions`
- 默认模型：`deepseek-chat`

已生成可导入文件：

- `我该发什么.shortcut`：未签名原始文件，仅供调试；
- `我该发什么-signed.shortcut`：使用 macOS `shortcuts sign --mode anyone` 生成，优先导入此文件。

签名文件会依次询问 API Key、主题、目标读者和内容目标，然后请求 DeepSeek；导入后可直接测试。

## 创建步骤

按以下顺序添加动作：

1. **询问输入**：
   - 问题：「最近你想分享或讨论什么？」
   - 输入类型：文本
   - 启用听写，可直接说一段经历或观察。
2. 将回答保存为 `主题`。
3. **询问输入**：
   - 问题：「这条内容主要写给谁？」
   - 默认值：「对该主题感兴趣的 X 用户」
   - 保存为 `目标读者`。
4. **从菜单中选取**内容目标：
   - 分享判断
   - 提供方法
   - 讲一个案例
   - 引发讨论
5. **询问输入**账号定位（可选）：
   - 问题：「你的账号定位是什么？可以留空。」
   - 保存为 `账号定位`。
6. **文本**动作保存 API Key，内容为你的 DeepSeek Key。建议不要分享包含此动作的快捷指令。
7. **词典**动作创建请求体：

```json
{
  "model": "deepseek-chat",
  "temperature": 0.8,
  "response_format": { "type": "json_object" },
  "messages": [
    {
      "role": "system",
      "content": "你是内容选题助手，帮助用户解决‘我现在该发什么’。不要泛泛罗列热点，不要虚构用户经历或事实。基于用户输入，给出三个具体、可执行、适合 X 短帖的选题。每个选题必须包含 title、angle、hook、outline、why。只输出 JSON：{\"ideas\":[{\"title\":string,\"angle\":string,\"hook\":string,\"outline\":string,\"why\":string}]}"
    },
    {
      "role": "user",
      "content": "主题：{{主题}}\n目标读者：{{目标读者}}\n内容目标：{{内容目标}}\n账号定位：{{账号定位}}"
    }
  ]
}
```

在快捷指令中，`{{主题}}`、`{{目标读者}}`、`{{内容目标}}`、`{{账号定位}}` 使用对应的魔法变量替换。建议用「词典」动作逐层创建字段，不要把整段 JSON 当作普通文本拼接。

8. **获取 URL 内容**：
   - URL：`https://api.deepseek.com/chat/completions`
   - 方法：`POST`
   - 请求体：`JSON`
   - 请求头：
     - `Content-Type: application/json`
     - `Authorization: Bearer [API Key 文本动作]`
   - 请求体使用上一步的词典。
9. 从返回词典读取：
   - `choices` → 第一个项目 → `message` → `content`。
10. 对 `content` 使用 **从输入获取词典**或 **获取词典值**解析 JSON。
11. **重复** `ideas` 数组中的每个项目，整理以下字段：

```text
{{title}}
切入角度：{{angle}}
开头：{{hook}}
结构：{{outline}}
为什么适合：{{why}}
```

12. 用换行合并 3 个选题。
13. 使用 **快速查看**显示结果，并提供 **复制到剪贴板**动作。
14. 可选增加 **追加到备忘录**，保存到「X 选题」笔记。

## 使用方式

1. 运行「我该发什么」。
2. 直接口述最近的经历、观察或问题。
3. 选择目标读者和内容目标。
4. 查看 3 个选题。
5. 复制一个选题继续写，或保存到备忘录。

## 安全边界

- API Key 写在快捷指令中时，不要把快捷指令分享给别人。
- 不要把未公开的客户、公司或个人信息发送给第三方模型。
- 选题是辅助发散，不代表事实已经核验。
